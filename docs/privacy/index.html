Что хранится на устройстве

LLM Dict сохраняет записи и импортированное аудио, улучшенные версии аудио, расшифровки, результаты обработки, названия, даты, длительность, флажки и сообщения об ошибках. Здесь же находятся ваши промпты, инструкции и настройки.

Последняя исходная расшифровка Live также может сохраняться отдельно, чтобы её можно было открыть снова. API-ключи хранятся в системном Keychain. Обычная запись и локальное улучшение звука не требуют передачи содержимого разработчику.

Разработчик не предоставляет собственный сервер для хранения ваших записей. Данные приложения могут включаться в резервные копии устройства средствами Apple — в зависимости от ваших системных настроек.

Локальная модель и дополнительные сервисы в версии 1.1

В версии 1.1 переключатель «Транскрибация на устройстве» применяется к записям и Live. После скачивания Whisper распознаёт речь на iPhone с интернетом и без него; аудио для этого распознавания не отправляется в облако. При ошибке приложение не переключается на облако автоматически. Локальный Live создаёт исходную расшифровку; перевод, резюме и другие инструкции требуют отдельной обработки текста.

Кнопка скачивания получает проверенные файлы Core ML из официального репозитория Argmax argmaxinc/whisperkit-coreml и токенизатор из репозитория OpenAI на Hugging Face. Hugging Face и его инфраструктура доставки получают сетевые сведения, включая IP-адрес; записи и расшифровки при скачивании не передаются. Условия платформы: политика конфиденциальности Hugging Face. Файлы модели хранятся локально, исключены из резервного копирования и удаляются кнопкой «Удалить модель» в настройках; записи при этом остаются в библиотеке.

В облачном режиме для распознавания записи можно выбрать OpenAI или СалютСпич. СалютСпич получает аудио, а его сервис авторизации — данные авторизации. Для оформления текста можно выбрать OpenAI или GigaChat; GigaChat получает текст, промпт и данные авторизации. Облачный Live использует OpenAI. До ввода ключа и первого запроса требуется отдельное согласие для выбранного сервиса. После возврата GigaChat и СалютСпич прежние согласия для них сбрасываются. Отзыв согласия отменяет текущие запросы и блокирует новые; наличие ключа не заменяет согласия.

Получатели дополнительных облачных запросов: smartspeech.sber.ru для СалютСпич, api.giga.chat для GigaChat и ngw.devices.sberbank.ru:9443 для авторизации. Сроки хранения и условия обработки определяются вашим аккаунтом и документами соответствующего провайдера: СалютСпич, GigaChat. Локальный режим распознавания не делает последующую облачную обработку текста офлайн.

Когда данные передаются AI-сервисам

В версии 1.0 перед вводом ключа и отправкой данных нужно явно отметить согласие в «Настройки → Сервисы и ключи» для OpenAI. По умолчанию согласие не дано; наличие сохранённого ключа само по себе не означает согласия. Рядом указаны передаваемые данные, получатель и ссылка на эту политику. Приложение сохраняет на устройстве версию согласия, дату и адрес получателя. При смене адреса OpenAI API согласие сбрасывается.

Получатель определяется выбранной функцией, сервисом и адресом API:

Распознавание записи
Аудио отправляется в OpenAI или на указанный вами совместимый адрес для преобразования речи в текст.
Live
Во время Live аудиопоток и настройки сессии отправляются в OpenAI или на указанный вами совместимый адрес. В режимах, поддерживающих инструкции, передаётся и выбранная инструкция.
Обработка текста
Исходный текст и промпт отправляются в OpenAI или на указанный вами совместимый адрес для выполнения вашей инструкции.
Подключение и список моделей
Ключ или полученный на его основе токен используется для авторизации у соответствующего сервиса. Провайдер также получает сетевые сведения, необходимые для соединения, включая IP-адрес.

Если вы изменяете адрес OpenAI API, запросы, содержимое и данные авторизации получает оператор указанного адреса. Его условия обработки могут отличаться от условий OpenAI. Используйте только доверенный адрес.

Хранение у провайдеров

Облачные сервисы обрабатывают данные по условиям ваших аккаунтов и выбранных API. Их сроки хранения и география обработки могут отличаться; данные могут обрабатываться вне вашей страны.

В текущей реализации запросы обработки текста через OpenAI Responses API не отключают сохранение ответа. По документации OpenAI данные таких ответов по умолчанию сохраняются не менее 30 дней, с учётом исключений и настроек аккаунта. Отдельные журналы безопасности регулируются собственными правилами.

Для срока хранения и удаления у выбранного провайдера используйте его настройки и документы: OpenAI — обработка данных API. Приложение не управляет серверным хранением провайдера и не гарантирует немедленное удаление уже отправленных данных.

Ваш выбор и удаление данных

  • Обычная локальная запись доступна без согласия на облачную обработку.
  • Снимите галочку согласия в «Настройки → Сервисы и ключи», чтобы запретить новые запросы этому сервису и отменить текущую облачную обработку. Это не удаляет уже переданные провайдеру данные.
  • Доступ к микрофону можно отозвать в системных настройках iOS.
  • Удаление записи из библиотеки с подтверждением удаляет её аудио и текст. В версии 1.0 также очищается относящаяся к ней отдельная копия последнего текста Live. Очистка экрана Live не удаляет запись из библиотеки.
  • Ключ сервиса можно удалить в настройках. Это не отменяет подписку у провайдера и не удаляет его данные.
  • Удаление локальной записи не удаляет экспортированные файлы, отправленные письма, резервные копии и данные у провайдеров. Управлять этими копиями нужно в соответствующем сервисе.

Локальные данные остаются на устройстве до удаления пользователем или средствами системы. Для вопросов об удалении напишите на llmdict.support@gmail.com. Разработчик не имеет удалённого доступа к библиотеке на вашем устройстве.

Обращения в поддержку

Если вы отправляете письмо, поддержка получает ваш email, текст и добровольно приложенные файлы. Кнопка в приложении добавляет в черновик версии приложения и iOS; отправку подтверждаете вы.

Переписка используется для ответа, диагностики и решения вашего вопроса и хранится, пока необходима для этих целей. Вы можете запросить её удаление по тому же адресу. Не присылайте API-ключи, пароли или чужие персональные данные без необходимости.

Ящик поддержки работает в Gmail. Обработку писем почтовым провайдером описывает политика конфиденциальности Google.

Сайт, аналитика и передача файлов

В приложении нет рекламных или сторонних аналитических SDK. Этот сайт не содержит рекламной аналитики, форм загрузки и не сохраняет настройки в cookies или localStorage. Выбор языка открывает соответствующую страницу.

Сайт размещён на GitHub Pages. GitHub регистрирует IP-адреса посетителей для безопасности сервиса: информация GitHub Pages об обработке данных.

Когда вы используете «Поделиться» или копируете текст, выбранные вами приложения и получатели обрабатывают переданные им данные по своим правилам.
