Quick answers

Frequently asked questions

How do I get started?
  1. Allow microphone access and make a regular recording.
  2. For transcription, open Settings → Services and Keys, read the data-sharing disclosure, check the consent box, add your own OpenAI API key, and check the connection.
  3. Select a transcription or text-processing model. Then open a recording in the library.
Do AI services have separate charges?

Cloud processing uses your own accounts and API keys for OpenAI. Access, usage limits and charges are set by the selected provider. A consumer chat subscription and API access may be billed separately.

Why is transcription or Live not working?

Check your data-sharing consent in the service settings, connection, microphone permission, API key, access to the selected model and provider usage limits. For OpenAI, also check the API address and service availability in your region.

If the problem persists, send the error message, service name and steps to reproduce it. Please do not include your key.

How do I change the app, speech or translation language?

Choose Russian, English or System in Settings → App Language. Speech and translation languages are configured separately in Live settings. Changing the interface language does not translate saved recordings or your instructions.

How do I delete a recording and the last Live text?

Swipe left on a library recording, choose Delete and confirm. In version 1.0, this removes the recording, its audio files and text, including the separate saved copy of the last Live text when it belongs to that recording.

Clear Screen in the Live instruction menu clears the current screen and its saved state, but does not by itself delete the library recording.

Can I record offline?

Regular recording, playback and local audio enhancement run on your device. Cloud transcription, text processing and Live require a connection to the selected AI service.

Does local transcription in TestFlight 1.1 work offline?

Yes. Download the model in Settings → Local transcription and enable “On-device transcription.” This applies to recordings and Live. Downloading requires an internet connection; Whisper then works on your iPhone. Speed depends on the device. If Live falls behind, audio is saved for transcription in the library. Formatting with GigaChat or OpenAI requires an internet connection.
